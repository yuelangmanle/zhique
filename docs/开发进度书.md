## PM 级使用逻辑审计战果（2026-10-02 第二轮）

| 问题（PM/重度用户视角） | 根因 | 修复 |
|---|---|---|
| 二三级界面状态栏重叠 | targetSdk 36 强制 edge-to-edge，各屏未处理 insets | ZhiqueApp 根节点统一 systemBarsPadding（全屏一改全对） |
| 点▶/项目卡点不进、白屏、返回退出应用 | 项目卡空 onClick / 无 BackHandler / 无回退链 | 卡片点开、**三级回退链**（运行器→编辑器/Agent/对话→返回逐级还原，非掉回首页） |
| 网页里 `<input type=file>` 无反应 | onShowFileChooser 未实现 | 注入 ActivityResult 文件选择器（含系统 GET_CONTENT 兜底） |
| 网页外链点击替换项目页且回不去 | shouldOverrideUrlLoading 未实现 | 外链转系统浏览器；about/data/blob 域内放行 |
| `window.open`/`target=_blank` 无反应 | onCreateWindow 未实现 | 同一 WebView 承载 |
| 网页下载无反应 | DownloadListener 未实现 | 转系统下载器 |
| 返回键直接退出运行器（多页网页） | 缺少浏览器回退语义 | 返回键=网页回退（**跳过 about:blank 初始页**，无历史才退出） |
| 空白新建后没有反馈 | createEmpty 只入库不打开 | 自动打开（与示例一致） |
| 项目 AI 对话不知道"这个项目"是什么 | 对话未携带项目上下文 | 首条 system 消息注入 index.html（截 6000 字符） |
| 编辑器"问 AI 这段"跳设置 tab 导航断裂 | 走设置子页承载 | 改全屏对话 + 编辑器回退链 |
| 项目卡无编辑直达 | 只能先运行再编辑 | 长按菜单加「编辑代码」 |
| WebGPU 恒显示降级（假阴性） | 能力检测跑在 about:blank（非安全上下文，navigator.gpu 恒 undefined） | 项目页加载后重测覆盖初判 |
| 模型列表拉取失败 | baseUrl 带 /v1 时拼出 /v1/v1/models | modelsUrl 去重（版本段感知）+ 单测锁定 |
| Apilot 授权闪退 | REQUEST_ID 触发 FragmentActivity requestCode 越界 | 稳定 key 显式注册 launcher |
| Apilot 检测不到（明明装了） | Android 11+ 包可见性：manifest 缺 queries | 补 `<queries>` 声明 |
| 顶栏黑带"织雀"（B2） | 无 themes.xml → 系统 ActionBar | NoActionBar 主题 + 状态栏配色 |
| WebGPU 降级提示一闪而逝 | Toast 无留存 | 改抽屉常驻徽标 |
