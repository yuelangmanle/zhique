# 织雀（Zhique）项目书

> 安卓手机上的 HTML 运行器 + AI 编程助手——粘贴即跑、AI 自写自调、权限全桥接、一键打包发布。
> 版本 0.1.0-in-development · Apache-2.0 · 原生 Kotlin

---

## 1. 为什么做这个

AI 助手写 HTML 程序已经又快又好，但安卓用户拿到代码后依然寸步难行：

- **打开难**——手机浏览器加载本地 HTML 兼容性差、没有调试手段，WebGL/WebGPU 页面基本跑不起来；
- **改不动**——页面报错只能干瞪眼，手机上没有 console、没有断点，更没有能看报错改代码的工具；
- **用不了**——网页调不了相机、文件、传感器这些系统能力，AI 写的程序永远只是"能看"；
- **留不下**——好的 HTML 程序没法变成手机桌面上一个真正的 App。

织雀把这四件事一次做完：**从任何 AI 复制代码 → 打开织雀 2 次点击运行 → 报错交给内置 Agent 自动修复 → 满意后一键打包成独立 APK → 甚至直接发布到 GitHub。**

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| AI 编程爱好者（核心） | 在 ChatGPT/DeepSeek 写了个小工具/小游戏，想在手机上立刻玩、随手改 |
| 独立开发者 | 把 HTML 原型快速变成可分发的安卓 App，顺手开源 |
| 普通用户 | 拿到别人分享的 HTML 程序/APK，当普通 App 用 |

作者本人为第一重度用户；项目开源到 GitHub（`stable` / `beta` 双更新通道，App 内自更新）。

## 3. 核心能力（F1–F11）

### 运行与编辑
- **F1 智能粘贴**：一次粘贴全搞定——完整 HTML、说明文字混代码块、HTML/CSS/JS 分开的多个代码块、裸片段，自动识别、清洗（markdown 围栏、行号污染）、组装、命名、入库；规则拿不准时内置 AI 兜底解析；每一步清洗透明可撤销。
- **F2 三模式运行器**：系统 WebView 全量渲染（CSS/JS/WebGL/WebGPU/Canvas），底部抽屉 / 上下分屏 / 悬浮球浮层三种界面随时切换；调试抽屉含报错/Console/网络，可选 eruda 高级面板。
- **F3 轻编辑器**：语法高亮 + 选中即问 AI，大改动交给 Agent。

### AI 能力
- **F4 多协议 Provider**：OpenAI 兼容 / Anthropic / Gemini 三协议原生适配，自带 Key 即用；每个模型带能力声明（能否看图）；输出上限、防截断自动续写、思考过程独立折叠展示。
- **F5 Agent 自主调试**：像电脑上的编程智能体——自己跑页面、读报错、改代码、重跑验证、截图自查，循环到修好为止；轮数/token 预算可控，每步快照可回滚，全程审计。
- **多模型协作**：不同模型干不同的活（主力规划、便宜模型跑循环、视觉模型看截图），可组合可预设。

### 系统能力
- **F6 权限桥**：网页可用相机/麦克风/文件/定位/传感器/蓝牙/通知/剪贴板/分享/截屏——标准 W3C API 零改动兼容，织雀 `zq.*` API 覆盖更多；**App 集中持权，网页按需申请，用户逐项授权随时吊销**。
- **提示词桥**：把织雀的 API 规范一键生成提示词发给外部 AI，让它一次写对兼容代码。

### 变成真正的 App
- **F7 打包导出**：端上组装 + 官方 apksig 签名，HTML 项目一键变独立 APK；**签名密钥一次生成永久复用，备份到电脑，机制上保证每次更新可覆盖安装**；每项目独立包名可共存；桌面快捷方式轻量可选。
- **F8/F11 GitHub 发布**：手动模式只负责点确认（日常 2 步），或让 Agent 出计划代办；发布是持久化状态机，中断可续跑、换模式可接管；项目与仓库绑定后一键推送更新。
- **F9 Apilot 桥接**：与 [Apilot](https://github.com/yuelangmanle/Apilot)（API 管理工具）官方 V2 协议互操作——API 配置双向授权流转，密钥最小暴露。

## 4. 体验主张

- **Aurora Glass 设计语言**：晨光/深空双域、低饱和极光光晕、系统级实时毛玻璃（RenderEffect）、镜面高光、发光交互；全线非线性弹簧动效（抽屉过冲、按压回弹、悬浮球形变），120Hz。
- **触点纪律**：粘贴到运行 ≤2 触、报错到 Agent 1 触、出包 3 触、日常推送 1 触 + 1 确认。

## 5. 架构与技术

原生 **Kotlin + Jetpack Compose + 系统 WebView**（独立进程渲染，崩溃不拖垮主体）；11 个 Gradle 模块分层（UI / 粘贴管道 / Web 运行时 / AI Provider / Agent 编排 / 权限桥 / 导出管线 / 发布状态机 / Apilot 桥 / 公共库）；核心逻辑全部纯 JVM 可测。

**开源策略**：底层用十年打磨的成熟件——sora-editor（编辑器）、JGit（Git）、apksig（签名）、OkHttp/SSE、WebViewAssetLoader；产品层全部自研（权限桥、粘贴管道、Agent 编排与三层记忆、发布状态机、导出管线）。

**安全与隐私**：API Key AES 加密、主密钥在系统安全区；无账号无云服务，数据全在本机；Agent 外发动作默认逐项确认；首次用云 API 前明确告知代码将发往你配置的服务商。
